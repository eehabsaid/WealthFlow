# Internationalisation (en / ar / fr / de)
- Files: `static/i18n/en.json`, `ar.json`, `fr.json`, `de.json`. The same keys in all four, with identical `{placeholders}`.
- A new visible text = a new key in all four files (check: `core/tests/i18n/test_i18n_keys.py` and `coding_agent` verify step "i18n parity").
- JS: `t("key", "English fallback")` or `_aiT(...)`; HTML: `data-i18n="key"`; the base currency is the `{base}` token.
- Documentation texts: `doc_engine/content/page_descriptions.json`, `doc_engine/inventory.json`; regenerate with `scripts/generate_docs.py` and `manage.py generate_ai_knowledge`.
- Arabic must render right-to-left; fr/de text is often longer, so avoid fixed widths.
